# DS 6021: Final Project - LoanWise: Loan Default Prediction
An interactive machine learning project exploring loan default patterns through data analysis, visualization, and predictive modeling.

### Overview
LoanWise investigates borrower characteristics and financial factors associated with loan default. The project uses exploratory data analysis and machine learning to better understand and predict potential default risk.

## Dataset
- Observations: 255,347
- Features: 18
- Target Variable: Default
- Task: Binary Classification (Default / No Default)

## To get started:
Clone the repository:

- git clone <https://github.com/sayuri005/DS6021_Final_Project/>
- cd App

- streamlit run app.py
