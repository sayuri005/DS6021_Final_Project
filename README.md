# DS 6021: Final Project 

### Overview
This project works through the credit loan default dataset found on kaggle (https://www.kaggle.com/datasets/nikhil1e9/loan-default) and implements both supervised and unsupervised models to determine if an individual will default on their loans. The final project is a published application presenting the models findings as well as a final presentation. 

## Models and Technologies Used

- logisitc regression
- KNN
- Random Forest
